# Git Hands-On Solutions Guide

This directory contains complete, step-by-step solutions and shell command workflows for all **Git Hands-on Labs (HOL 1 to HOL 5)**.

## Hands-On Lab 1: Git Configuration & Basic Commands (Git-HOL-001)

### Objectives
- Configure Git environment with username, email, and default editor.
- Initialize a local Git repository `GitDemo`.
- Create and track `welcome.txt`.
- Perform commits, view status, log, and push to remote repository.

### Step-by-Step Commands
```bash
# 1. Check Git version
git --version

# 2. Configure Global User Information
git config --global user.name "John Doe"
git config --global user.email "johndoe@example.com"

# 3. Verify Git Configuration
git config --list

# 4. Integrate Notepad++ as default editor (Windows)
git config --global core.editor "'C:/Program Files/Notepad++/notepad++.exe' -multiInst -notabbar -nosession -noPlugin"
git config --global -e

# 5. Initialize Git Repository
mkdir GitDemo
cd GitDemo
git init

# Verify hidden files (.git folder)
ls -la

# 6. Create welcome.txt and add content
echo "Welcome to Git Version Control System!" > welcome.txt
cat welcome.txt

# 7. Check Repository Status
git status

# 8. Stage welcome.txt for tracking
git add welcome.txt

# 9. Commit changes with a descriptive message
git commit -m "Initial commit: Added welcome.txt file"

# 10. Remote Repository Operations
git remote add origin https://github.com/your-username/GitDemo.git
git branch -M main
git push -u origin main
```

## Hands-On Lab 2: Ignoring Files with .gitignore (Git-HOL-002)

### Objectives
- Understand `.gitignore` functionality.
- Configure `.gitignore` to ignore `.log` files and temporary `log/` folders.

### Step-by-Step Commands
```bash
# 1. Create a log file and a log folder in working directory
echo "Debug log data" > app.log
mkdir -p logs
echo "Server error log" > logs/server.log

# 2. Create .gitignore file
echo "*.log" > .gitignore
echo "logs/" >> .gitignore

# 3. Check Git Status (app.log and logs/ directory should be ignored)
git status

# 4. Stage and Commit .gitignore
git add .gitignore
git commit -m "Add .gitignore to ignore log files and directories"

# 5. Verify tracked files
git ls-files
```

## Hands-On Lab 3: Branching & Merging (Git-HOL-003)

### Objectives
- Create a new feature branch `GitNewBranch`.
- Make changes in the branch and commit them.
- Compare branch differences using `git diff` and merge back into `master`/`main`.
- Delete the feature branch after merging.

### Step-by-Step Commands
```bash
# 1. Create and switch to new branch GitNewBranch
git checkout -b GitNewBranch

# Verify current active branch (marked with *)
git branch

# 2. Add new files to the branch
echo "Feature implementation details" > feature.txt
git add feature.txt
git commit -m "Feature: Added feature.txt in GitNewBranch"

# 3. Switch back to main/master branch
git checkout main

# 4. Compare differences between main and GitNewBranch
git diff main..GitNewBranch

# 5. Visual diff using P4Merge or default difftool
git difftool main..GitNewBranch

# 6. Merge GitNewBranch into main
git merge GitNewBranch

# 7. View visual commit graph
git log --oneline --graph --decorate --all

# 8. Delete the merged feature branch
git branch -d GitNewBranch

# Verify remaining branches
git branch
```

## Hands-On Lab 4: Conflict Resolution (Git-HOL-004)

### Objectives
- Simulate and resolve merge conflicts when multiple branches modify the same lines of a file (`hello.xml`).
- Use 3-way merge tools or manual conflict markers resolution.

### Step-by-Step Commands
```bash
# 1. Ensure working directory is clean
git status

# 2. Create branch GitWork
git checkout -b GitWork

# 3. Create hello.xml in GitWork branch
cat << 'EOF' > hello.xml
<?xml version="1.0" encoding="UTF-8"?>
<greeting>
    <message>Hello from GitWork branch!</message>
</greeting>
EOF

git add hello.xml
git commit -m "GitWork: Created hello.xml with GitWork content"

# 4. Switch back to main branch
git checkout main

# 5. Create hello.xml on main with DIFFERENT content
cat << 'EOF' > hello.xml
<?xml version="1.0" encoding="UTF-8"?>
<greeting>
    <message>Hello from Main branch!</message>
</greeting>
EOF

git add hello.xml
git commit -m "Main: Created hello.xml with Main content"

# 6. Attempt to merge GitWork into main (will trigger merge conflict)
git merge GitWork

# 7. Observe conflict status
git status

# 8. Resolve Conflict in hello.xml
cat << 'EOF' > hello.xml
<?xml version="1.0" encoding="UTF-8"?>
<greeting>
    <message>Hello from Main branch and GitWork combined!</message>
</greeting>
EOF

# 9. Add backup files to .gitignore if generated by merge tools (*.orig)
echo "*.orig" >> .gitignore

# 10. Stage resolved file and commit merge resolution
git add hello.xml .gitignore
git commit -m "Merge branch 'GitWork': Resolved conflict in hello.xml"

# 11. Delete GitWork branch
git branch -d GitWork

# 12. Check git log graph
git log --oneline --graph --decorate --all
```

## Hands-On Lab 5: Clean Up & Push to Remote (Git-HOL-005)

### Objectives
- Verify clean status of local repository.
- Synchronize local repository with remote (pull latest changes and push merged commits).

### Step-by-Step Commands
```bash
# 1. Verify working directory cleanliness
git status

# 2. Fetch and pull latest changes from remote
git pull origin main --rebase

# 3. Push local commits to remote repository
git push origin main

# 4. Verify branch history
git log -n 5 --oneline
```
